About

I am an M.Sc. student in Computer Science at Mila and Université de Montréal, supervised by Prof. Bang Liu. I study memory for embodied agents: what an agent should keep from what it sees and is told, how that memory stays valid while the world changes out of view, and when it should and should no longer drive action.

Research

  • Memory for embodied agents Episodic, semantic and spatial memory built from egocentric experience; keeping memories valid when the world changes unobserved.
  • Evaluating agents from world state Benchmarks with matched twin episodes and deterministic grading of actions rather than answers; reactive decision-making in embodied multimodal LLMs.
